# Fundamentos de Python para Dados

Exercícios de estudo realizados a partir da trilha de Analista de Dados da Alura, utilizando Python e Google Colab.

## Conteúdo

| Notebook | Conteúdo atual |
| --- | --- |
| [Coleta_e_amostragem_de_dados.ipynb](Coleta_e_amostragem_de_dados.ipynb) | Entrada de nome, idade e altura, conversão de tipos e apresentação de mensagens. O nome do arquivo será revisto para refletir esse conteúdo. |
| [Calculadora_com_operadores.ipynb](Calculadora_com_operadores.ipynb) | Exercícios de operadores aritméticos e tratamento de denominador zero. |

## Como executar

1. Baixe o notebook desejado.
2. Abra o Google Colab e importe o arquivo `.ipynb`.
3. Execute as células em ordem e informe os valores solicitados.

Os exercícios utilizam entradas digitadas pela pessoa usuária e operações da biblioteca padrão do Python.
